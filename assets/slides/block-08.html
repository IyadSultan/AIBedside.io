The new staff

Agents need
their own rules

Not the same thing

A chatbot answers. An agent does work.

A generic language model

  • Sits in a browser tab
  • Forgets you tomorrow
  • Cannot act on a chart
  • Not allowed near a child

A hospital agent

  • Has a named job
  • Reads, remembers, learns
  • Can face a family — or build the hospital’s AI
  • Works only with a human in the loop

Two jobs, not one toy

They can stand at the bedside, or behind it.

When it fails

An agent error is an incident.

Not a glitch. Not “the model was having a day.” The same investigation as a missed dose.

  1. Name itWho owns this agent?A person, not a vendor slide.
  2. Watch itLife cycle, in the openBorn, supervised, updated, retired.
  3. See itOutput is visibleIf you cannot see the work, you cannot govern it.
  4. InvestigateFull incident reviewDocument. Learn. Change the rule.
